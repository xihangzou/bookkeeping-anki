# Pilot card-level validation

Issue: ANKI-PILOT-003 (#47)

## Scope

This validation reviews every Cloze card generated by `pilot/notes.tsv` under the v0.9 authoring contract.

- Pilot Notes reviewed: **40 / 40**
- Generated Cloze cards reviewed: **63 / 63**
- Source baseline: `xihangzou/bookkeeping-integrated@569ed7b82e729334e1472286eaca7c4352e6fbdb`
- Evidence: `pilot/card_validation.tsv`

A card is treated as Anki-style rendered by hiding every occurrence of its active `cN` group while leaving all other Cloze groups visible. In `card_validation.tsv`, `targets` records the hidden answer(s) and `visible_other_answers` records answers that remain visible on that card. This makes counterpart/parallel-answer leakage auditable without relying on the unrendered Note alone.

## Check contract

Each card row records all required review dimensions using `P` = pass, `W` = warning, `F` = fail:

- `acct`: accounting accuracy
- `amb`: unambiguous target / answer form
- `ctx`: context sufficiency
- `atom`: atomicity / coherent recall unit
- `ans`: answer size
- `num`: Cloze numbering/grouping quality
- `dup`: duplicate or near-duplicate retrieval risk
- `src`: source traceability
- `repeat`: usefulness after repeated review
- `leak`: rendered-card leakage, including visible Cloze groups, journal-entry counterparts, grammar/layout, parallel formulas, and over/under-masking

Defects are never recorded only as prose. Every non-pass row has a stable `defect_codes` value and severity (`minor`, `major`, or `blocking`).

## Blocking findings

### BK-FND-00-0014 c2 — `ANSWER_FORM_AMBIGUITY`

Target: `本来の勘定科目`.

The card gives no concrete transaction after the temporary-account stage, so multiple semantically correct answer forms can fit. The prompt therefore does not have a sufficiently unique retrieval target. This is blocking because v0.9 requires ambiguous prompts to be fixed before the v1.0 gate.

### BK-COM-01-0010 c1–c3 — `COMPARISON_AXIS_MISMATCH`

The Note lead-in says `売上原価を把握する時点`, but the 分記法 branch asks for `商品売買益`. The pinned source comparison is broader: `売上原価・利益の算定時点`. The current Note therefore mixes the timing dimension with the object being calculated and is not a coherent same-axis comparison. All three generated cards inherit the malformed comparison context; c2 is additionally answer-category ambiguous.

## Major findings

### BK-FND-00-0017 c2 / BK-COM-01-0004 c1 — `SEMANTIC_DUPLICATE`

Both cards test the same proposition:

`純仕入高 = 総仕入高 - 仕入戻し高`

The commercial version currently adds no new judgment or condition, so repeated review would duplicate the same retrieval unit. This is the intended S1 cross-context stress case and must be resolved explicitly in ANKI-PILOT-004 rather than silently retained.

## Recurring warning patterns to hand off to ANKI-PILOT-004

- `POSITIONAL_SEQUENCE_CUE`: separate `cN` cards in ordered procedures expose neighboring stages and therefore part of the missing stage's position.
- `PARALLEL_RELATION_CUE` / `PARALLEL_FORMULA_CUE`: a visible paired relation or formula materially narrows the hidden parallel answer.
- `LARGE_COUPLED_ANSWER`: compound journal entries remain coherent but some cards approach the practical answer-size ceiling.
- `SYNONYM_VARIANT` / `ANSWER_OVERSPECIFIED`: canonical wording should not imply that equivalent accounting language is wrong.
- `LOW_RETRIEVAL_VALUE`: some table-derived associations may become trivial after repetition even though they remain accurate and unambiguous.

Warnings are evidence for rule revision; they are not auto-promoted to blocking defects. ANKI-PILOT-004 must distinguish recurring patterns from one-off authoring issues and decide the corrective rule or documented no-change rationale.
